# **Introduction(소개)**

The CoCoder Program is a CLI code editor written in the C language.

코코더 프로그램(CoCoder Program)은 C언어로 제작된 콘솔 환경의 코드 에디터입니다.

[![Development Note p.155](https://img.youtube.com/vi/6cy6-cgZK9Y/0.jpg)](https://www.youtube.com/watch?v=6cy6-cgZK9Y)

# **How to Use(사용법)**

When you write C code in the console window that appears after launching CoCoder.exe and press the ESC key, the code is saved, compiled, and the resulting executable file is run.

CoCoder.exe 프로그램을 실행한 후에 나타나는 콘솔 화면에 C언어 코드를 작성하여 ESC 키를 누르면, 작성된 코드가 저장되면서 동시에 컴파일을 진행하고 생성된 exe 파일을 실행합니다.

## **Common Problems(자주 겪는 문제)**

If you press the ESC key after writing the code but the path `C:\NewLand\CoCoder` does not exist, saving the file may fail.

To prevent this, please create the folder corresponding to that path in advance.

코드를 작성하고 ESC 키를 눌렀지만, ```C:\NewLand\CoCoder``` 경로가 존재하지 않으면 파일 저장에 실패할 수도 있습니다.

따라서 이를 방지하고자 미리 위의 경로에 해당하는 폴더를 생성해 주세요.
